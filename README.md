# Приёмник сигналов

Небольшое Android-приложение (Android 7.0 и старше, minSdk 24): слушает локальную сеть, получает POST-запросы и озвучивает имя русским офлайн-голосом Google с вибрацией. Для сигналов без текста используется системный звук уведомления. Сторонних библиотек в рабочей части нет.

Сеть предполагается доверенной и контролируемой владельцем: приём сигнала не требует токена или иной авторизации — любой POST из локальной сети считается сигналом.

## Как пользоваться

1. Установите и запустите «Приёмник сигналов», нажмите «Запустить». Приёмник слушает порт 8765 (значение меняется на экране).
2. На экране показан IP-адрес телефона в локальной сети и пример готовой команды.
3. Компьютер или сервер в той же сети отправляет сигнал:
   `curl -X POST "http://192.168.0.239:8765/notify?message=Новая%20задача"`
   Ответ — JSON `{"status":"ok"}`.
4. Телефон озвучивает текст, вибрирует и записывает событие в «Последние сигналы».

Другие варианты:

- Простой сигнал: `curl -X POST "http://IP:8765/notify"`
- Текст в теле: `curl -X POST "http://IP:8765/notify" -H "Content-Type: text/plain; charset=utf-8" --data-binary "Иван Петров"`
- Русский текст без ручной кодировки: `curl -X POST "http://IP:8765/notify" --data-urlencode "message=Новая задача"`

## Озвучивание имени без интернета

Приёмник использует Android TextToSpeech с явно выбранным движком Google
(`com.google.android.tts`) и установленным русским голосом, который не требует сети.
Сетевые голоса и голоса с признаком незавершённой установки не выбираются.
Установите «Синтезатор речи Google» / «Распознавание и синтез речи от Google»,
нажмите «Установить русский офлайн-голос», загрузите русский язык и перезапустите
приёмник. Для установки движка и голоса нужен интернет; для озвучивания — нет.
Состояние голоса отображается под кнопкой тестового сигнала.

Приоритет текста: заголовок `X-Scud-Notification/name`, заголовок `name`,
параметр `name`, параметр `message`, затем обычное текстовое тело либо поле
`message` формы `application/x-www-form-urlencoded`. JSON не озвучивается.
Пример: `curl -X POST "http://IP:8765/notify?name=%D0%98%D0%B2%D0%B0%D0%BD"`.
Поле name отправителя из face_recognition_system поддерживается без изменений.

Имя произносится вместо звука уведомления; вибрация сохраняется. Пустое сообщение
даёт обычный сигнал. Если голос недоступен, запрос всё равно принимается и звучит
обычный сигнал. Имена произносятся последовательно; при запуске ожидают подготовки
движка. Максимум 160 символов в имени и 10 ожидающих имён; при переполнении удаляется
самое старое ожидающее имя. Остановка службы отменяет очередь и освобождает TTS.
Громкость зависит от системного канала уведомлений и режима «Не беспокоить».

Проверка на телефоне: загрузите голос, отключите доступ в интернет, оставив локальный
Wi-Fi, запустите приёмник и отправьте имя. Проверьте также несколько имён подряд,
запрос сразу после запуска, выключенный экран, остановку во время речи и отсутствие
русского голоса. Ответ HTTP 200 означает приём события, а не завершение озвучивания.

## Защита потока запросов

- Принимаются только POST-запросы, тело не более 64 КиБ, заголовки ограничены по размеру, дублирующиеся заголовки отвергаются, GET и другие методы получают 405.

## Ограничения

- Сигнал из интернета придёт только при пробросе порта на роутере или через туннель; настройка не входит в поставку.
- Приёмник работает как foreground-сервис с постоянным уведомлением и удерживает частичную блокировку пробуждения до 24 часов. На части устройств режим энергосбережения может задерживать запросы при погасшем экране — для надёжной работы отключите оптимизацию батареи для «Приёмник сигналов» в системных настройках.

## Сборка

```sh
sh gradlew assembleDebug testDebugUnitTest lintDebug
```

APK появится в `build/outputs/apk/debug/`. Технологии: Java 17, стандартные Android Views, `ServerSocket`, Gradle 8.2 / Android Gradle Plugin 8.2.0.

Структура: `HttpReceiver.java` — HTTP-слушатель и ответы, `HttpRequest.java` — строгий разбор одного POST-запроса, `AlertPlayer.java` — звук и вибрация, `ReceiverService.java` — фоновая служба со списком событий, `MainActivity.java` — экран с портом, IP-адресом и логом. Тесты: `HttpRequestTest.java`, `HttpReceiverTest.java` (последний проверяет работу через настоящий сокет).
